# ADR-0001：LLM 不直接修改正式行程

- 状态：Accepted
- 日期：2026-07-28

## 背景

模型擅长理解自然语言和生成候选行动，但地图事实、硬约束和正式行程变更必须可复现、可审计。

## 决策

LLM 仅能输出通过 Pydantic 校验的意图或 Action Proposal。POI 必须来自 Provider。路线由确定性求解器生成。正式计划以不可变版本保存；所有重要修改先生成 Plan Patch，经用户确认和确定性复验后才能产生新版本。

## 后果

- 优点：硬约束可测试，变更可回放，模型升级不会直接改变生产数据。
- 代价：多一次验证和版本写入；动态重规划需要保存足够的事实快照。
- 不采用：多 Agent 自由讨论后直接覆盖路线。
